# Пліткарка — стартовий Telegram-бот

Це початковий прототип: меню, категорії, демонстраційний пошук і форма надсилання історії.
Історії зберігаються зі статусом `pending` у SQLite; цей варіант призначений для тестування,
а не для публічного запуску з реальними персональними даними.

## Потрібно для запуску
- Python 3.11+
- Токен Telegram-бота від @BotFather

## Локальний запуск
1. Встановити залежності: `pip install -r requirements.txt`
2. Встановити змінну середовища `BOT_TOKEN` (не вставляйте токен у код).
3. Запустити: `python main.py`

## Хостинг
Для безперервної роботи потрібен хостинг, що підтримує постійний worker або webhook.
Для публічного запуску спершу замініть SQLite на керовану PostgreSQL-базу та додайте
закритий модераторський інтерфейс, процедуру оскарження/видалення, правила спільноти
і захист від помилкової ідентифікації. Безкоштовні тарифи можуть засинати або мати обмеження.

## Налаштування спільноти
Необов'язкові змінні:
- `COMMUNITY_CHAT_URL` — запрошення до Telegram-групи
- `STORIES_CHANNEL_URL` — посилання на канал зі стрічкою історій
- `DB_PATH` — шлях до SQLite-файлу (лише для тестування)

Ніколи не публікуйте токен у коді, GitHub або чатах. Якщо токен розкрився, відкличте його через @BotFather.
